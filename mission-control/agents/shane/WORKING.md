## How to Use This Board

**Adding a task to INBOX:**
Drop a row with a task ID (create the full card in `/tasks/<id>.md` if needed),
the source (human / agent / scheduled), and the date received.

**Moving to ACTIVE:**
When Shane picks up or routes a task, move it to ACTIVE and note the owner
(agent ID or "Shane"). Record the start date.

**Moving to REVIEW:**
When an agent completes a task and output needs human eyes, move it to REVIEW.
Note what action is needed: approve / reject / revise / just FYI.

**Moving to DONE:**
After human approval or final resolution. Note the outcome in one line.
Archive old DONE rows to `/tasks/archive/` when the table exceeds 10 rows.
